# 行情助手 · 翻译官与异动侦探

手机端「行情解读智能体助手」的高保真交互原型。目标用户是没有专业背景的财富管理 App 用户，解决的问题是"看到自选股涨跌，却无法快速理解发生了什么"。

## 设计要点

- **三态归因**：有据归因 / 弱据归因 / 存疑。不确定时明确标注"归因存疑"，不编造理由。
- **证据链**：每条归因可展开查看来源，支持从异动时间线回到对话追问。
- **合规边界**：免责声明常驻；触发红线时降级为"仅事实播报"。
- **主动触达**：重要度门槛 + 冷却时间 + 免打扰，避免变成打扰用户的通知器。
- **分级审核**：L1-L4 定级，达到 L3 方可灰度，稳定达 L4 且投诉率达标方可全量。

## 运行

纯静态、零外部依赖：直接用浏览器打开 `index.html` 即可，无需构建。

## 说明

页面内的行情数据与个股均为模拟内容，仅用于演示交互，不构成任何投资建议。
